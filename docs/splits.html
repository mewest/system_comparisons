Reviewed events are analyst-reviewed onsite events (status preliminary, reviewed or final). Every other onsite event within ±3 min of a reviewed event is a test event: its first-arriving P picks are compared with the arrival times predicted from the reviewed event's hypocenter (ak135). RMS is the root-mean-square of those residuals in seconds. If it is small, the reviewed event already explains the test event's picks and the test event is likely a split (duplicate solution). If it is large, the test event needs its own source. Classes: split if RMS ≤ 1.5 s (with ≥ 5 P picks); distinct if RMS ≥ 3 s and at least twice the RMS of the test event's picks against its own hypocenter; otherwise ambiguous. Labels for checking the thresholds: rejected (test event rejected on onsite) and both reviewed (the test event is also a reviewed event, so the analyst kept both).
